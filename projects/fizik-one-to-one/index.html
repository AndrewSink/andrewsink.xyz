3D Printing 2024

fizik - One-to-One

The fizik One-to-One program allows cyclists to generate a customized 3D printed saddle using real-time pressure mapping data and an advanced algorithm from gebioMized.

Designed and printed using cutting-edge Carbon DLS technology and software. My role in this project was creating the zonal lattice structure, creating a workflow to generate customized geometry for each rider, and optimizing for manufacturability. Launched in 2024.
